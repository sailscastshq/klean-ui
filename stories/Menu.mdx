<Description />

Menu is one accessible interaction layer over Klean Popover. Connect a real Button
with native `popovertarget`; put real buttons and links inside. Menu supplies
`menuitem` semantics, roving focus, Arrow keys, Home/End, typeahead, dismissal,
and focus return. Your ordinary Tailwind classes supply the product design.

```sh
npx klean-ui@latest add menu
```

The installer detects Vue, React, or Svelte and adds both Menu and its Popover
prerequisite. It creates no configuration file, provider, helper, or trigger component.

## API

Menu only adds interaction. `id`, `placement`, `offset`, optional observed open state,
and the ordinary `class`/`className` attribute are the complete surface. There is no
`MenuTrigger`, `MenuItem`, `asChild`, visual variant, or Klean theme API.

Native button and anchor children become menu items automatically. A disabled native
button or `aria-disabled="true"` link is skipped. Use a native anchor or the Boring
Stack Link for navigation, and a native button for an action.
