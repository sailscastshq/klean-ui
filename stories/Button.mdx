Klean UI keeps the button contract deliberately small: choose the truthful element,
pass its native attributes, and style it with ordinary Tailwind classes. There are no
visual variants to learn or theme configuration to maintain.

## API

The props below change behavior or semantics. Use `class` for every visual decision.

## Related components

- [Popover](?path=/docs/components-popover--docs) — connect Button with native `popovertarget` when it opens non-modal content.
- [Menu](?path=/docs/components-menu--docs) — use when a Button opens a keyboard-navigable list of actions or destinations.
- [Dialog](?path=/docs/components-dialog--docs) — use when the action opens a modal task or confirmation.
- [Slide](?path=/docs/components-slide--docs) — reserve for consequential actions that benefit from deliberate pointer confirmation.
