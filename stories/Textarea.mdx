Textarea is a styled native control with one durable behavior: its presentation
is derived from the current value and width.

```sh
npx klean-ui@latest add textarea
```

<Canvas of={TextareaStories.Playground} />

## Vue recipe

```vue
<div class="grid gap-2">
  <label for="note">Internal note</label>
  <Textarea
    id="note"
    v-model="form.note"
    name="note"
    :aria-invalid="Boolean(form.errors.note)"
    aria-describedby="note-help note-error"
  />
  <p id="note-help">Plain text, up to 2,000 characters.</p>
  <p id="note-error" class="empty:hidden text-sm text-red-700">
    {{ form.errors.note }}
  </p>
</div>
```

There is no `Field`, label prop, description prop, error prop, or `autoGrow`
switch. The error node and description IDs stay stable even while the error is
empty. Native markup owns the relationship, and caller `h-*`, `resize-*`, and
`overflow-*` classes can take visual ownership.

## API

Textarea accepts native textarea attributes, framework-native value binding,
`class`, and exposes its native element for explicit focus recovery.
