export const remoteUsage = `<script setup>
import { ref } from "vue"
import Combobox from "@/components/ui/combobox/Combobox.vue"

const repository = ref()
const repositories = ref([])
const loading = ref(false)
let request

async function search(query) {
request?.abort()
request = new AbortController()
loading.value = true

try {
const response = await fetch(\`/api/repositories?q=\${encodeURIComponent(query)}\`, {
signal: request.signal,
})
repositories.value = await response.json()
} catch (error) {
if (error.name !== "AbortError") throw error
} finally {
if (!request.signal.aborted) loading.value = false
}
}

</script>

<template>
  <Combobox
    v-model="repository"
    :options="repositories"
    :loading="loading"
    @search="search"
  />
</template>`;

Combobox is the editable choice picker. The input filters the options immediately,
while a debounced `search` event lets the application replace or extend those options.
The committed value remains unchanged until the user chooses an option.

```sh
npx klean-ui@latest add combobox
```

The zero-configuration installer detects Vue, React, or Svelte and adds Combobox plus
Klean Popover. No provider, configuration file, generated class helper, or compound
part API is required.

## Select or Combobox?

Use **Select** for a known, reasonably short fixed list. Use **Combobox** when typing
helps: a long customer list, a repository search, an assignee, a relationship field,
or remotely loaded suggestions. Search is not a Select variant because editable and
select-only controls have different browser, keyboard, focus, and assistive-technology
contracts.

## Remote search

Combobox emits `search` after 300 ms when it opens and as the query changes. The first
query is empty, so an application can supply a useful initial page. It does not own a
URL, credentials, pagination, or response shape. Abort a replaced request in the
application and pass the resulting `options`, `loading`, and `error` back in. Existing
options remain usable while loading.

## API

Options use `{ value, label, description?, disabled?, group?, keywords? }`. `keywords`
adds searchable aliases without changing what people see. Vue uses `v-model`, React
uses `value` with `onValueChange`, and Svelte uses `bind:value`. Query and open bindings
exist for the uncommon application that genuinely needs to observe those ephemeral
states.

`class` or `className` merges onto the real input, so caller Tailwind wins. Stable
`data-slot` and state attributes support focused recipes without part-class props.
There are no variants, tones, sizes, themes, provider objects, or trigger components.

## Accessibility and durable behavior

Give Combobox a visible `<label>` or accessible name. DOM focus stays on the editable
input while `aria-activedescendant` identifies the highlighted option. Arrow keys,
Home, End, and Enter navigate and commit; disabled options are skipped. Escape closes
and restores the committed label. Tab closes and continues in ordinary document order.
Outside interaction uses Popover light dismissal. Pending search timers are replaced
and cleaned up automatically.

The query, open state, and highlight are temporary by default. Persist the selected
application value in the form, server, URL, or storage only when the product needs it.
