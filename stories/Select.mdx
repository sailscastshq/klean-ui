Select chooses one persistent value from a known, fixed list. It preserves your
primitive values instead of turning every choice into a string, submits through
ordinary forms, and gives pointer, touch, keyboard, and assistive-technology users
the same outcome.

```sh
npx klean-ui@latest add select
```

The zero-configuration installer detects Vue, React, or Svelte and adds Select with
everything it needs. No provider, configuration file, shared helper, or part-component
ceremony is created.

## When to use Select

Use Select when the choices are known, reasonably short, and the user is choosing
one value: a role, status, environment, region, branch, billing interval, or sort order.
Use a native `<select>` when the browser-owned picker already fits the product. Klean
Select is for the same job when you need copied-source styling, grouped choices, a
consistent selected indicator, or a constrained long list.

## When not to use Select

- Use **Combobox** when the user types a query, filters a long list, or waits for remote suggestions. Search will not become a `searchable` Select mode.
- Use **Menu** for actions and navigation. A menu item does something; a Select option becomes the current value.
- Use radios when a small set of choices should remain visible for immediate comparison.
- Use checkboxes or a purpose-built multi-select pattern when more than one value may be chosen.

## API

The option convention is `{ value, label, disabled?, group? }`. Vue uses `v-model`,
React uses `value` with `onValueChange`, and Svelte uses `bind:value`. The equivalent
open bindings are available when application code genuinely needs to observe the
surface. `name`, `required`, `disabled`, `form`, `aria-*`, and ordinary event attributes
retain their native meaning.

`class` or `className` merges onto the visible trigger, so caller Tailwind wins. There
are no `variant`, `tone`, `size`, theme, or part-class props. Stable `data-slot` and
state attributes cover focused product recipes; because the source is yours, the final
escape hatch is simply editing it.

Vue slots (`value`, `option`, `icon`, `empty`), React render functions, and Svelte
snippets may change the rendering without changing the selection contract.

## Accessibility

Give Select a visible `<label>` or an accessible name. Arrow keys move the visual
highlight without silently changing the committed value; Enter or Space commits.
Home and End reach the enabled edges, printable keys provide typeahead, Escape cancels,
and Tab leaves in normal document order. Disabled options are skipped and focus returns
to the trigger after a choice.
