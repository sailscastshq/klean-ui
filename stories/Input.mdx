Input is one styled native control. Klean does not hide the surrounding form
markup behind a Field abstraction.

```sh
npx klean-ui@latest add input
```

<Canvas of={InputStories.Playground} />

## Vue recipe

```vue
<div class="grid gap-2">
  <label for="email">Email address</label>
  <Input
    id="email"
    v-model="form.email"
    name="email"
    type="email"
    :aria-invalid="Boolean(form.errors.email)"
    aria-describedby="email-help email-error"
  />
  <p id="email-help">We only use this for account messages.</p>
  <p id="email-error" class="empty:hidden text-sm text-red-700">
    {{ form.errors.email }}
  </p>
</div>
```

The application owns the visible label, deterministic IDs, validation timing,
help, and error text. The stable relationship needs no helper or conditional ID
logic. Input forwards the native attributes and merges caller Tailwind classes
last.

## API

Input accepts native input attributes, framework-native value binding, `class`,
and nothing resembling a visual variant or field configuration API.
