# Klean UI

One workbench, three honest framework implementations.

Use the **Vue**, **React**, and **Svelte** sections in the sidebar to inspect the
components rendered by each framework. The stories import the same copied source
that `npx klean-ui add` installs; this shell only composes their Storybooks.

Klean UI keeps framework APIs idiomatic, leans on native browser behavior, uses
semantic HTML, and treats ordinary Tailwind classes as the visual API.
