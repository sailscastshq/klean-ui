Schedule Picker turns an intended future wall-clock time into an exact ISO
instant. Natural language is available by default, but its interpretation stays
visible until the user presses Enter or leaves the complete picker.

```sh
npx klean-ui@latest add schedule-picker
```

<Canvas of={SchedulePickerStories.Playground} />

## When to use

Use Schedule Picker for publishing, sending, deploying, appointments, or jobs
that must happen at a future time. Supply the account or application IANA
timezone when it is known; otherwise Klean uses the browser timezone.

## When not to use

Use Date Picker when only the day matters. Use Date Range Picker for reporting
periods. Use Calendar when the calendar itself is the workspace.

## Vue

```vue
<SchedulePicker
  v-model="form.publishAt"
  name="publishAt"
  time-zone="Africa/Lagos"
  required
/>
```

## React

```jsx
<SchedulePicker
  value={publishAt}
  onValueChange={setPublishAt}
  name="publishAt"
  timeZone="Africa/Lagos"
  required
/>
```

## Svelte

```svelte
<SchedulePicker
  bind:value={publishAt}
  name="publishAt"
  timeZone="Africa/Lagos"
  required
/>
```

Typing `Friday at 9am`, `in 5 minutes`, or `in one hour` creates a proposal.
Press Enter, leave the complete picker, or choose **Use this time** to commit
it. Moving focus between the field, calendar, and time list does not commit
prematurely. Relative durations retain their exact seconds. The hidden named
form value remains the last valid ISO instant, so incomplete or ambiguous
drafts cannot silently change a schedule. The default time list uses 15-minute
choices; `minuteStep` changes that list, while typed times may remain exact.

## Related components

Schedule Picker combines date, time, and IANA timezone as an exact ISO instant.
Choose the date-only components below when wall-clock time must not exist.

- [Date Picker](?path=/docs/components-date-picker--docs) — one date-only `YYYY-MM-DD` value without time or timezone.
- [Calendar](?path=/docs/components-calendar--docs) — an always-visible date-only `YYYY-MM-DD` surface.
- [Date Range Picker](?path=/docs/components-date-range-picker--docs) — ordered date-only `YYYY-MM-DD` periods.
- [Popover](?path=/docs/components-popover--docs) — the non-modal floating behavior.
- [Toast](?path=/docs/components-toast--docs) — announce the server result after a schedule is saved.
