Calendar is the visible date-selection surface. It returns a date-only
`YYYY-MM-DD` value; it never invents a time or timezone.

```sh
npx klean-ui@latest add calendar
```

<Canvas of={CalendarStories.Playground} />

## When to use

Use Calendar when the calendar should remain visible: availability views,
booking steps, dashboards, or any screen where comparing nearby dates is the
task.

## When not to use

Use Date Picker for one date inside a form. Use Date Range Picker for a start
and end. Use Schedule Picker when time and timezone change the meaning.

## Vue

```vue
<Calendar v-model="form.date" min="2026-08-01" :unavailable="isUnavailable" />
```

## React

```jsx
<Calendar
  value={date}
  onValueChange={setDate}
  min="2026-08-01"
  unavailable={isUnavailable}
/>
```

## Svelte

```svelte
<Calendar bind:value={date} min="2026-08-01" {unavailable} />
```

The day grid supports arrows, Home/End, Page Up/Down, and Shift + Page Up/Down.
Locale controls weekday order and labels; direction is inferred unless supplied.
Ordinary caller Tailwind classes can target the stable `data-slot` and date-state
attributes.
